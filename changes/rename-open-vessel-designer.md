- OVCD is now Open Vessel Designer (OVD). The repository, crates, the `ovd` command, the Python package (`open-vessel-designer`, `import ovd`) and the app use the new name. The old names no longer work. Design files keep the `.vdesign` extension, but files saved by 0.2.x do not open in 0.3.0.
- Rename (spec 0010, ADR 0022): the crates are `ovd-core`, `ovd-format`, `ovd-cli`, `ovd-py`, `ovd-shell`, `ovd-web` and `ovd-app`; the command is `ovd` (`ovd.exe`, `ovd.wasm`); the app is OVD, with the identifier `org.africanrivercorridors.ovd` and the file type "OVD Design"; environment variables start `OVD_` and browser storage keys `ovd.`, and the old ones are not read, so the app shows the first-run notice again and starts with no stored Design or settings. The project Rule Set is `ovd` 3.0.0, with the Rules of the old 2.1.0 and ids that start `ovd/`; its earlier versions are gone, and `RELEASED.json` no longer lists the old id. A file that stores the old Rule Set id fails with one error that names the rename. Every `.vdesign` in the repository stores `ovd` 3.0.0 with its hash. No result and no results hash moves: every fixture and example gives the same results before and after, apart from the Rule Set id, version and hash. The website moves from `/ovcd` to `/ovd`, with no redirect. `tools/old_name_gate.py` (in the fast gate) fails on the old name outside the history.
